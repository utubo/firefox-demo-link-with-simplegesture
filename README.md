# Demo link with Simple Gesture

## Usage

1. Install [Simple Gesture](https://addons.mozilla.org/ja/firefox/addon/simple-gesture/)
2. Install this.
3. Firefox Settings  
  ->Extensions  
  ->Demo Link with Simple Gesture  
  ->Permissions  
  ->Turn on `Allow for all sites`
4. Simple Gesture Settings  
  ->Custom Gesture  
  ->Assign a gesture to `Demo link with Simple Gesture`
5. Gesture in a site with normal URL
